# «Булочка» — Cozy Fast Food v6

Теперь кафе стало заметно живее.

## Что нового

- Четыре типа посетителей:
  - зайчики;
  - котики;
  - лисички;
  - мишки.
- У зверят разные цвета и имена.
- У входа появилась очередь из трёх посетителей.
- После выдачи заказа следующий зверёк подходит к кассе.
- Очередь автоматически пополняется.
- Обслуженный гость идёт за столик.
- За столиком у него появляется именно та еда, которую он заказал.
- В зале одновременно могут сидеть несколько гостей.
- В начале нового дня столики освобождаются.

## Как запустить

1. Распакуй архив.
2. Открой Godot 4.
3. Import → выбери `project.godot`.
4. Нажми ▶ или F6/F5.

## Управление

WASD — ходить  
Мышь — смотреть  
E — взаимодействовать  
Esc — отпустить мышь  
ЛКМ — снова захватить мышь

## Игровой цикл

1. Посмотри заказ гостя у стойки.
2. Приготовь нужные позиции.
3. Еда появляется на физическом подносе.
4. Выдай заказ.
5. Гость идёт к столику.
6. Очередь сдвигается и приходит следующий посетитель.
